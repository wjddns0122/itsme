# 03. 화면 명세

> 디자이너(팀원 B)와 개발이 함께 보는 문서. Figma 프레임 이름은 화면 ID와 같게 짓는다 (`P-03 분실 신고`).
> 문구는 이 문서가 기준이다. 바꾸려면 이 문서를 고친다.

---

## 1. 공통 디자인 규칙

| 항목 | 규칙 |
|---|---|
| 기준 폭 | 분실자 화면 360px (모바일), 관리자 화면 1024px (태블릿 가로·노트북). A-03은 360px도 지원 |
| 터치 영역 | 44px 이상 |
| 글자 대비 | 4.5:1 이상 |
| 디자인 토큰 | 팀원 A가 Day 1 저녁에 확정: 주색, 보조색, 성공/경고/위험색, 폰트, 모서리 둥글기 |
| 컴포넌트 | shadcn/ui 기반. 새 컴포넌트가 필요하면 B가 Figma에 먼저 그린다 |
| 문체 | "~해요"체. 짧게. 기술 용어(AI, 임베딩, 점수) 노출 최소화 |
| 상태 | 모든 화면은 **기본 / 빈 상태 / 로딩 / 에러** 네 가지를 그린다 |

상태 배지 (색은 토큰 확정 후 지정)

| 값 | 표시 문구 |
|---|---|
| `stored` | 보관 중 |
| `claimed` | 확인 중 |
| `returned` | 반환 완료 |
| `transferred` | 경찰 이관 |
| `disposed` | 처리 완료 |
| 매칭 후보 있음 | 후보 n |
| 유사도 0.70 이상 | 유사도 높음 |
| 유사도 0.45~0.70 | 유사도 보통 |

## 3. 분실자 화면

### P-02 시설 랜딩

- 목적: QR로 들어온 사람이 무엇을 할지 바로 고르게 한다.
- 구성
  - 시설 이름, 로고(있으면)
  - 큰 버튼 2개: **"물건을 잃어버렸어요"** → P-03 / **"물건을 주웠어요"** → P-06
  - 안내데스크 연락처, 운영 시간
  - 하단: "잇츠미로 운영돼요"
- 에러: 없는 slug → "시설을 찾을 수 없어요. QR 코드를 다시 확인해 주세요."

### P-03 분실 신고

- 목적: 60초 안에 신고. 상단에 진행 표시 `1/3`.
- **1단계 — 무엇을 잃어버렸나요?**
  - 여러 줄 입력 (필수, 10자 이상). 자리표시: "예) 검은색 무선 이어폰인데 케이스에 은색 키링이 달려 있어요."
  - 분류 칩 (선택): 휴대폰, 이어폰, 지갑·카드, 가방, 옷·장갑, 고글·헬멧, 안경, 열쇠, 기타
  - 도움말: "색상, 브랜드, 달려 있던 것, 흠집처럼 기억나는 걸 모두 적어주세요."
- **2단계 — 언제, 어디서 잃어버렸나요?**
  - 날짜 범위 (시작~종료, 기본값 오늘~오늘). 빠른 선택: 오늘 / 어제 / 최근 3일
  - 구역 선택: 시설 구역 목록 + "잘 모르겠어요"
- **3단계 — 연락받을 곳**
  - 이메일, 전화번호 (둘 중 하나 이상 필수). 이름 (선택)
  - 나만 아는 특징 (선택): "케이스 안쪽 스티커, 이니셜처럼 남은 모르는 특징을 적어주세요. 관리자만 볼 수 있어요."
  - 동의 체크 (필수): "분실물 반환을 위해 연락처를 수집해요. 신고가 끝나고 30일 뒤 삭제해요." + 전문 보기
  - 버튼: **"신고하기"**
- 검증 에러 문구
  - 설명 짧음: "조금 더 자세히 적어주세요 (10자 이상)."
  - 연락처 없음: "이메일이나 전화번호 중 하나는 꼭 필요해요."
  - 동의 안 함: "동의해야 신고할 수 있어요."
- 로딩: 버튼에 스피너, 중복 제출 막기.

### P-04 신고 현황·후보

- 목적: 신고 상태와 후보를 확인. 로그인 없이 링크로 접근.
- 첫 진입(`?new=1`) 배너: **"신고했어요! 이 페이지 주소를 저장해 두세요."** + [링크 복사] (이메일 입력 시: "이메일로도 보냈어요.")
- 구성
  - 내 신고 요약: 설명 첫 줄, 분실 기간, 구역, 상태 배지
  - 후보 영역
    - 분석 중: "비슷한 물건을 찾고 있어요…" (5초마다 새로고침)
    - 후보 없음: "아직 비슷한 물건이 없어요. 새로 들어오면 알려드릴게요."
    - 후보 카드 (최대 5개): 분류 아이콘, 공개 설명, 습득일, 구역, 유사도 배지, 버튼 [내 물건 같아요] [아니에요]
  - 확인 요청 중: "관리자가 확인하고 있어요. 보통 하루 안에 연락드려요."
  - 승인됨: 수령 안내 카드 (장소, 운영 시간, 지참물, 연락처)
  - 하단: [신고 취소]
- 금지: 습득물 사진, 비공개 특징, 점수 숫자를 보여주지 않는다.
- 에러: 없는 토큰 → "신고를 찾을 수 없어요."

### P-05 소유권 확인 요청

- 목적: 진짜 주인인지 관리자가 판단할 정보를 받는다.
- 구성
  - 선택한 후보 요약 (공개 정보만)
  - 질문 (필수): "이 물건이 내 것이라고 알 수 있는 특징을 적어주세요. 위 설명에 없는 내용일수록 좋아요."
  - 사진 첨부 (선택): "같은 물건을 들고 찍은 사진, 구매 내역 등"
  - 버튼: **"확인 요청하기"**
- 완료 후 P-04로 이동.
- 이미 진행 중인 요청이 있으면: "이미 확인 중인 요청이 있어요. 결과가 나오면 다시 요청할 수 있어요."

### P-06 습득물 맡기는 방법

- 맡기는 곳(안내데스크 위치), 운영 시간, 연락처, 간단한 지도 이미지(시설이 올린 경우).
- 문구: "주워주셔서 감사해요! 안내데스크에 맡겨주시면 주인에게 돌려드릴게요."

## 4. 관리자 화면

공통 레이아웃: 왼쪽 메뉴 (대시보드, 습득물, 확인 요청 n, 분실 신고, 설정), 상단에 시설 이름과 로그아웃. 모바일 폭에서는 하단 탭.

### A-01 로그인

- 이메일, 비밀번호, [로그인]. 에러: "이메일 또는 비밀번호가 맞지 않아요."

### A-02 대시보드

- KPI 카드 4개: 보관 중 / 확인 요청 대기 / 이번 달 반환 / 이번 달 반환율
- 할 일 목록: 확인 요청 대기 (→ A-06), 이관 기한 3일 이내 (→ A-05)
- (컷 가능) 최근 7일 습득·반환 막대 차트
- 큰 버튼: **[+ 습득물 등록]** (항상 보이게, 모바일에서는 하단 고정)
- 빈 상태: "아직 등록한 습득물이 없어요. 첫 습득물을 등록해 보세요."

### A-03 습득물 등록 ★ 핵심

- 목적: 15초 안에 등록.
- 1단계 — 사진
  - 큰 촬영 영역: [사진 찍기] (모바일 카메라 직접), [앨범에서 선택]. 최대 3장
  - 업로드 후 썸네일 + "AI가 물건을 살펴보고 있어요…" (스켈레톤 양식)
- 2단계 — 확인·수정 (AI가 채운 값, 수정 가능)
  - 분류 (드롭다운), 세부 종류 (텍스트), 색상 (칩 다중 선택), 브랜드 (텍스트, "추정" 라벨)
  - 공개 설명 (여러 줄): 라벨 옆 "분실자에게 보여요"
  - 비공개 특징 (여러 줄): 라벨 옆 자물쇠 아이콘 + "관리자만 봐요. 주인 확인에 써요"
  - 민감 물품 스위치 (AI가 켜면 경고 배너: "신분증·카드로 보여요. 사진은 공개되지 않아요.")
  - 습득 일시 (기본값 지금), 습득 구역 (드롭다운), 보관 위치 (텍스트, 직전 값 기본)
  - 버튼: **[저장]** / [저장하고 계속 등록]
- AI 실패: 노란 배너 "AI 분석이 안 됐어요. 직접 입력해 주세요." + 빈 양식
- AI가 채운 필드는 옅은 배경색으로 표시, 관리자가 고치면 일반 배경으로 바뀐다.

### A-04 습득물 목록·검색

- 상단: 검색창 "어떤 물건을 찾으세요? 예) 검은 이어폰 은색 키링", 필터 (상태, 분류, 기간)
- 표 (태블릿) / 카드 (모바일): 썸네일, 분류, 공개 설명, 습득일, 보관 위치, 상태 배지, 후보 n
- 검색 결과는 의미가 비슷한 순. 결과 없음: "비슷한 습득물이 없어요. 분실 신고를 대신 접수할까요?" → A-07
- 빈 상태: A-02와 같음.

### A-05 습득물 상세

- 왼쪽: 사진 (크게, 넘겨보기)
- 오른쪽: 상태 배지, 모든 정보 (비공개 특징 포함), [수정]
- 매칭 후보 섹션: 신고 요약, 유사도, 신고일, 상태. 후보를 누르면 신고 상세(서랍)
- 처리 이력: 시간순 (등록, AI 분석, 매칭, 확인 요청, 승인, 반환…)
- 액션: [반환 처리] (A-09), [경찰 이관], [폐기 처리] — 이관·폐기는 확인 대화상자

### A-06 소유권 확인 요청

- 목록: 요청 시각, 습득물 분류·썸네일, 분실자 이름(있으면), 대기 시간
- 상세 (2열 비교) ★ 핵심
  - 왼쪽 "분실자가 말한 것": 신고 원문, 나만 아는 특징, 확인 요청 답변, 첨부 사진, 연락처
  - 오른쪽 "보관 중인 물건": 사진, 공개 설명, **비공개 특징 (강조)**
  - 같은 습득물에 다른 요청이 있으면 경고: "이 물건에 다른 확인 요청이 n건 있어요."
  - 버튼: **[승인]** (수령 안내 메모 입력), [거절] (내부 메모, 분실자에게 안 보임)
- 승인 후: "수령 안내를 보냈어요." 이후 반환 처리는 A-09.

### A-07 분실 신고 목록·대리 신고

- 목록: 신고일, 설명 첫 줄, 분실 기간, 상태, 후보 수, 접수 경로 (QR/대리)
- [대리 신고 접수]: P-03과 같은 항목을 한 화면에. 완료 후 신고 링크를 보여주고 [복사] (전화로 불러주거나 문자로 보냄)

### A-08 시설 설정·QR

- 시설 이름, 연락처, 운영 시간, 수령 안내 문구, 구역 목록 (추가·삭제·순서), 보관 기한(일)
- QR 영역: QR 미리보기, [PNG 내려받기], (컷 가능) [A4 포스터 PDF]
- 포스터 문구: "물건을 잃어버리셨나요? / 주우셨나요? QR을 찍어주세요."

### A-09 반환 처리 (모달)

- 수령인 이름 (필수), 확인 방법 (신분증 확인 / 특징 문답 / 구매 내역 / 기타), 메모
- 연결된 신고가 있으면 자동 선택, 없으면 "신고 없이 반환" (방문 문의로 바로 돌려준 경우)
- 버튼: **[반환 완료]** → 토스트 "반환 완료했어요."
