argument-hint: "[비교 기준, 기본값 HEAD]"
---

현재 변경사항을 리뷰해. 비교 기준: $ARGUMENTS (비어 있으면 `HEAD`, 커밋 안 된 새 파일 포함)

1. `git diff`와 `git status`로 바뀐 파일 목록을 만들어.
2. 두 서브에이전트를 **동시에** 실행해. 각자에게 바뀐 파일 목록과 비교 기준을 넘겨:
   - `code-reviewer`: 정확성, 티켓 범위, 테스트, 문서 동기화
   - `security-auditor`: 권한(RLS), 개인정보 노출, 비밀값, 입력 검증
3. 두 결과를 합쳐서 심각도 순(🔴 차단 → 🟠 수정 권장 → 🟡 참고)으로 정리해. 중복은 합쳐.
4. 각 항목: `파일:줄 — 문제 — 고칠 방법`.
5. 고치지는 말고 보고만 해. 내가 고르면 그때 고쳐.
