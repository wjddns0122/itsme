다음 문제를 고쳐: $ARGUMENTS

1. 기대 동작을 문서에서 확인해 (`docs/01-prd.md`, `docs/02-user-flows.md`, `docs/03-screens.md`). 문서와 다른 기대라면 멈추고 물어봐.
2. 문제를 재현해. 재현 방법(명령, 입력, 화면 경로)을 적어.
3. 원인을 찾아. 추측으로 고치지 말고 코드와 로그로 원인을 확인해.
4. 원인을 드러내는 실패 테스트를 먼저 써.
5. 최소한으로 고쳐. 관계없는 리팩터링은 하지 마.
6. `pnpm check` 통과를 확인해.
7. 보고: 원인 한 줄 / 고친 내용 / 추가한 테스트 / 비슷한 문제가 있을 수 있는 다른 위치.
