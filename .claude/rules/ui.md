# 화면·문구 규칙

기준 문서: `docs/03-screens.md` (화면별 구성·문구), `docs/02-user-flows.md` (흐름)

- 문구는 `messages/ko.json`에 두고 가져다 쓴다. 문체는 "~해요"체, 짧게. AI·임베딩·점수 같은 기술 용어를 사용자에게 보이지 않는다.
- 문구는 `docs/03-screens.md`가 기준이다. 바꾸고 싶으면 문서를 먼저 고친다.
- 화면마다 기본 / 빈 상태 / 로딩 / 에러 네 가지를 만든다.
- 분실자 화면은 360px, 관리자 화면은 768px 이상을 기준으로 만든다. 습득물 등록(A-03)은 360px에서도 써야 한다.
- 터치 영역 44px 이상, 모든 입력에 `<label>`, 글자 대비 4.5:1 이상.
- `src/components/ui/`(shadcn)는 직접 고치는 것을 최소화한다. 필요한 변형은 감싸는 도메인 컴포넌트로 만든다.
- 분실자 화면(`src/app/(public)/`)에는 습득물 사진, 비공개 특징, 점수 숫자를 절대 렌더링하지 않는다. 유사도는 "높음/보통" 라벨로만.
- 사용자가 입력한 텍스트를 `dangerouslySetInnerHTML`로 렌더링하지 않는다.
- 색·폰트·둥글기는 디자인 토큰(`src/app/globals.css`의 CSS 변수)으로만 쓴다. 임의 색상값을 직접 쓰지 않는다.
